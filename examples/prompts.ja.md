# 例のプロンプト

スキルを入れたあとに、そのまま試せる依頼です。それぞれに、エージェントがすべきことを書いています。英語版は [prompts.md](prompts.md) にあり、試験の結果はそちらに記録しています。

## 1. 純ゲージの HMC を回して確かめる

> SU(3) の純ゲージを 4⁴ の格子で HMC して、正しく動いているか確かめて。

すべきこと：
- 設定の表を見せ、既定値で埋めた項目はそうと分かるように示します。
- まず `check_hmc.jl` を走らせ、検査ごとに PASS か FAIL かを報告します。
- `hmc_puregauge.jl` で短い鎖を走らせ、`monitor.jl` の結果を報告します。熱化で捨てた数と、WARN があればその内容も含めます。

## 2. 物理のパラメータが足りない依頼

> SU(4) の 3 次元の純ゲージを HMC して、熱化したか教えて。

すべきこと：
- β や格子の大きさを作り話で埋めません。聞くか、値を提案するならエージェント自身の提案だと示します。
- 鎖を走らせる前に、3 次元の格子で `check_hmc.jl colors=4` を走らせます。

## 3. 古いコードを直す

> 昔の台本の一部です。今の JuliaQCD で動くようにして。
> ```julia
> U = Initialize_Gaugefields(3, 0, 4, 4, 4, 4, condition = "hot")
> temps = Temporalfields(U[1], num=2)
> println(calculate_Plaquette(U, temps[1], temps[2]))
> ```

すべきこと：
- `import JACC; JACC.@init_backend` から始め、`gauge_configuration` と `measure_plaquette` で書き直します。
- 小さな格子で走らせ、ホットスタートのプラケットが 0 に近いことを確かめます。

## 4. JuliaQCD にないゲージ群

> JuliaQCD で SO(3) のゲージ理論をシミュレーションしたい。何が必要？

すべきこと：
- JuliaQCD v1 にあるのは SU(N) と U(1) だけだと言います。
- 使い回せる既存の部品と、足りないものを表にします。
- `GaugeGroups.jl` と `check_group.jl SO 3` を正解の基準に使い、本体を改造するより JuliaQCD に依存する別のパッケージとして作るよう勧めます。

## 5. ない機能

> QCDMeasurements で staggered の Dirac 演算子の固有値を測って。

すべきこと：
- QCDMeasurements の固有値の測定は Wilson だけに対応していると言います。
- 代わりに LatticeDiracOperators の `eigensystem` を示し、小さな格子の密行列の対角化と先に比べるよう注意します。
- staggered 用の QCDMeasurements の設定を作り話で書きません。

## 6. スケールとポテンシャルを測る

> juliaqcd-generate の台本で、SU(3) の純ゲージの配位を β = 5.7、6⁴ の格子で作った。置き場は runs/su3_b57。グラディエントフローから t0 と w0 を、Wilson ループから静的ポテンシャルを、誤差付きで求めて。

すべきこと：
- 測る前に、その置き場の `meta.toml` を読み、`monitor.jl` を走らせます。
- 配位と同じ群と次元で `check_measure.jl` を走らせます。
- 数個の配位で時間を測ってから、全体を測ります。
- t0/a² と w0/a をビンを取った誤差付きで、T ごとの a V(R)、Creutz 比、すべての WARN とともに報告します。
- 利用者が √t0 の fm での値を示さない限り、格子間隔を fm で出しません。

## 7. 論文の手法を実装する

> arXiv:hep-lat/9707022 にある Neuberger の overlap 演算子で、クエンチの SU(3) 配位の上のプロパゲーターを計算したい。まずは実装して。

すべきこと：
- overlap 演算子には、試験済みの手順がここにないと言います。
- 論文の式（式番号つき）から、必要なパーツに分けます。Wilson 核とソルバー（multishift CG）は JuliaQCD のものをそのまま使い、新しく書くのは符号関数と overlap 演算子の型だけにします。
- 利用者のプロジェクトに、JuliaQCD 互換の別パッケージとして作ることを提案し、通すテストを示します。小さな格子での密行列の符号関数、Ginsparg–Wilson 関係、γ₅ エルミート性、自由場、ゲージ共変性、わざと壊した版を検出できることです。
- ρ、クォーク質量、配位は、決めずに聞きます。

## 8. 計算機で本番を回す

> β = 6.0、16⁴ の格子で、Wilson 作用のクエンチ SU(3) の HMC を 1000 本、研究室の計算機 ws1 で回して（ssh で入れる）。終わったらプラケットの履歴を見せて。

すべきこと：
- 設定の表を見せ、MD の刻み数と乱数の種は既定値だと示し、1000 本に熱化を含むかを聞きます。
- `skills` のフォルダを ws1 に直接写し、環境をそこに作ります。
- 4⁴ で `check_hmc.jl` を走らせ、16⁴ の β = 6.0 で短く試し、時間・メモリ・ディスクの見積もりを見せてから了承を得ます。
- 本番はログを取りながら切り離して走らせ、終わったら `monitor.jl` を走らせ、熱化の切り捨てとともにプラケットの履歴を見せます。

## 9. 誤差付きのヒストグラム

> runs/b60 の配位で、トポロジカルチャージのヒストグラムを誤差付きで見せて。

すべきこと：
- まずその置き場の `meta.toml` を読み、`monitor.jl` を走らせます。
- Q をどのフロー時間で、どの定義で取るかを聞きます。
- 熱化を除いた配位ごとに数え、`jackknife` と `choose_bin` でビン付きの jackknife の誤差を付け、使ったビンを示します。
- 数え上げと図は、このスキル集では未検証のつなぎのコードだと断ります。

## 10. パイ中間子の有効質量

> β = 5.7、8³×16 の格子のクエンチ SU(3) 配位で、κ = 0.15 の Wilson フェルミオンでパイ中間子の有効質量を出して。

すべきこと：
- 配位の置き場を聞きます。これから作るなら、配位の数を聞きます。
- 測る前に `check_fermion.jl` を走らせます。
- `measure_mesons.jl` で測り、`analyze_mesons.jl` で解析します。
- m_eff のプラトーを誤差と Δt の範囲つきで出し、フィットはしていないと言い、プラトーがないという WARN があれば伝えます。

## 11. プラケットを文献と比べる

> β を 5.5 から 6.0 まで振ってプラケットの平均を測り、文献と比べて。

すべきこと：
- どの論文と比べるか、格子の大きさ、β の値を聞きます。プラケットの値を記憶から出しません。
- まず `check_hmc.jl` を走らせ、β ごとに 1 本ずつ走らせ、それぞれを `monitor.jl` で確かめます。
- 論文の表とページや表の番号を示して比べ、体積と統計の違いを述べます。

## 12. 格子間隔を fm で

> runs/su3_b60 の配位で t0 を出して、格子間隔を fm で教えて。

すべきこと：
- 6 と同じ手順で t0/a² を測ります。
- √t0 の fm での値を記憶から使いません。値とその出典の論文を聞き、そのうえで両方の誤差つきで a = √t0 / √(t0/a²) を出します。

## 13. 誤差が小さすぎる気がする

> プラケットの jackknife の誤差が小さすぎる気がする。何かおかしい？

すべきこと：
- 自己相関を疑います。ビンを取らない jackknife の誤差が自己相関のあるデータで小さく出ることは、`selftest_analysis.jl` が示しています。
- `gamma_method` で τ_int を、`choose_bin` と `jackknife` でビンの大きさごとの誤差を出し、ビンを大きくすると誤差が増えるかを見ます。
- プラケットは格子全体の平均なので、誤差が本当に小さいこともあると伝えます。
- データと、使ったビンと熱化の切り捨てを聞きます。

## 14. 自作の HMC を点検する

> Julia で SU(2) の HMC を自分で書いたが、刻み幅を小さくしても ΔH が小さくならない。何を確かめればいい？

すべきこと：
- 一般論だけで答えず、点検の順を示します。軌跡の長さを固定して刻み幅を変えているか、力が作用の中心差分と合うか、可逆性、rms ΔH ∝ δτ² と ⟨exp(−ΔH)⟩ = 1 です。
- `check_hmc.jl` の検査を手本に、`GaugeGroups.jl` の正確な指数関数と比べることを勧めます。
- 原因を名指しする前に、コードと出力を求めます。

## 15. 熱化と統計を判断する

> runs/b57/history.csv を見て、熱化したか、統計が足りているか判断して。

すべきこと：
- `monitor.jl` で熱化の切り捨て、受理率、⟨exp(−ΔH)⟩、Γ 法の τ_int を見て、独立な配位の数を数えます。
- 4 次元なら Q が動いているか（トポロジーの凍結）も見ます。
- ファイルがなければ、結果を作らずに置き場を聞きます。

## 16. 配位が壊れていないか

> confs/conf_01000.jld2 の配位が壊れていないか確かめて。

すべきこと：
- 読み込めるか、リンクが SU(N) に入っているか、NaN がないか、格子の大きさが合うかを調べ、プラケットを記録の値と照らします。
- ファイルがなければ、壊れていると決めつけずに置き場を聞きます。

## 17. 何時間かかるか

> クエンチ SU(3) の HMC を 32⁴ の格子で 1000 本回すと何時間かかる？

すべきこと：
- 一般知識で時間を言いません。計算機を聞き、短い試しで 1 本あたりの秒数を測ってから見積もります。試しの前には、仮の秒数から出した時間の幅も言いません。
- メモリ（SU(3) の 32⁴ のリンク場 1 つで約 0.6 GB、走らせると約 10 個分）とディスクは式から出します。
- β は物理のパラメータなので既定にしません。時間は β にほとんどよらないと断ったうえで、試しには任意の β を使えます。

## 18. 止まった run を続きから

> runs/b60 の run が 412 本目で止まった。続きから回して。

すべきこと：
- `meta.toml`、`state.toml`、`history.csv`、`checkpoints/` を読み、最後のチェックポイントから `restart=true` で再開します。
- 引数は `meta.toml` から取り、同じパッケージの版で、同じ計算機で走らせます。
- チェックポイントのあとの軌跡は同じ乱数で作り直されることを説明します。
- 止まった理由はログで確かめ、決めつけません。

## 19. Fortran のコードを移す

> SU(3)、Wilson 作用、熱浴と過緩和の純ゲージのコードを Fortran で自分で書いている。JuliaQCD に移したい。

すべきこと：
- パーツの表を作ります。熱浴と過緩和は Gaugefields の `heatbath_updater` をそのまま使い、作り直しません。
- 同じ格子と β で、Fortran の出力のプラケットと突き合わせる計画を立てます。
- 格子の大きさ、β、過緩和の回数を聞きます。

## 20. 更新したら値が変わった

> Gaugefields を更新したら、プラケットの値が変わった。なぜ？

すべきこと：
- 原因を決めつけません。古いのと新しいの、2 つの `Manifest.toml` を比べ、版の違うパッケージを挙げます。
- まず v1 より前のコードの規格化の違い（`calculate_Plaquette` は和を返す）を除きます。
- 同じ seed と格子で 2 つの環境で同じ検査を走らせ、1 つの保存した配位で比べます。乱数の流れが変わっただけなら、平均は誤差の範囲で合います。

## 21. Polyakov ループで閉じ込めの転移を見る

> Nt = 4 の格子で β を振って、Polyakov ループから SU(3) の非閉じ込め転移を見つけて。

すべきこと：
- 転移の β を記憶から出しません。空間の大きさ、β の範囲と間隔、本数を聞くか、論文を聞きます。
- `check_hmc.jl`、時間の試し、了承のあと、β ごとに 1 本ずつ走らせます。
- Polyakov ループは `history.csv` に記録されますが、検査はないので、感受率などは未検証のつなぎのコードだと断ります。

## 22. 弦張力

> Wilson ループから弦張力を出して。

すべきこと：
- 群、次元、格子、β、配位を聞きます。
- 2 次元では弦張力が厳密に出せること（`check_area_law.jl`）と、4 次元ではスメアリングの手順がまだないため σ は確かに出せず、a V(R) と Creutz 比までになることを分けて伝えます。

## 23. Schwinger 模型

> 2 次元の U(1) ゲージ理論（Schwinger 模型）で、動的フェルミオンのシミュレーションをしたい。

すべきこと：
- 動的フェルミオンには試験済みの手順がここにないと言います。
- 作るパーツ（2 次元の Dirac 演算子、擬フェルミオンの力など）と、通すテスト（密行列、γ₅ エルミート性、力と差分、可逆性、ΔH ∝ δτ²）を表にします。
- フェルミオンの種類、Nf、格子、β、質量を聞き、了承を得るまで書きません。

## 24. 論文の図を再現する

> arXiv:1006.4518 の Fig. 2 を再現して。

すべきこと：

- 論文の数を 1 つ再現してから図に進みます。
